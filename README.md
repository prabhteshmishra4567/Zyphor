# Zyphor Pharmaceutical

Company website and product portfolio for Zyphor Pharmaceutical, built with Next.js, React, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production

```bash
npm run build
npm start
```

Product images are stored in `public/products`, and the company logo is `public/logo.jpeg`. Local environment files are excluded from Git.
